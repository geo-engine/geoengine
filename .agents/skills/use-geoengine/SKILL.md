# Use Geo Engine

The guide for this task is a page of the documentation.
Read it completely before you write code, then follow its workflow and rules:

- in this repository: `www/src/content/docs/docs/getting-started/ai-agents.md`
- elsewhere: `https://www.geoengine.io/docs/getting-started/ai-agents.md`

Read the reference page of every operator and plot before you use it, and copy its example instead of guessing parameters:

- in this repository: `www/src/content/docs/docs/{operators,plots,datatypes,python}/`
- elsewhere: `https://www.geoengine.io/llms.txt` lists all pages as Markdown.

Links in the pages that start with `/docs/` are relative to these two locations.

In this repository, a notebook in `python/examples/` also follows the rules for example notebooks in `python/AGENTS.md`.
