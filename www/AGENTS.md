# AGENTS.md: Website and docs (Astro)

www-specific guidance. Repo-wide context (generated-code chain, PR rules) is in the root `AGENTS.md`. Inside this directory, drop the module prefix from the `just` recipes below (`just build` instead of `just www build`).

- `just www install`, `just www run` (dev server; `--preview` for a production build + preview), `just www build`
- `just www lint` (prettier check + eslint). Format with `just www format --write`.
- Astro + Starlight. Docs live under `src/content/docs/docs/`; the sidebar is configured in `astro.config.mjs`. `starlight-links-validator` fails the build on broken internal links.

## Generated docs: don't hand-edit

`just www build` regenerates parts of the docs through integrations in `plugins/`, and the output is committed. CI rebuilds www and fails on any git diff (`just repo lint-generated-code`).

- `src/content/docs/docs/operators/*.md` and `plots/*.md` are generated by `plugins/astro-openapi.ts` from the operator schemas in `../openapi.json`. To change them, edit the doc comments on the API operator types in `geoengine/services/src/api/model/processing_graphs/`, then regenerate the spec and rebuild www.
- `src/content/docs/docs/python/` is generated by `plugins/pydoc.ts` (pydoc-markdown via `pipx`, configured in `pydoc-markdown.yml`) from the docstrings in `../python/geoengine`.
- The `index.md` in each of these folders is hand-written and kept by the generators.
