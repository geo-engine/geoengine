Geo Engine is a cloud-ready platform for processing and visualizing geospatial data.
It has native support for time series and processes large datasets as streams.

This documentation is organized as follows:

- [**Getting Started**](/docs/getting-started/) explains who uses Geo Engine and how, and walks you through a first session.
- [**Concepts**](/docs/the-geo-engine/) describes how Geo Engine works: processing graphs, queries and streams, time, raster and vector data, datasets, layers, data connectors, and permissions.
  Read this to understand the behavior of the operators and the Python library.
- [**Interfaces**](/docs/api/) covers the REST API and the OGC services (WMS, WFS, WCS, OGC API Tiles).
- [**Datatypes**](/docs/datatypes/), [**Operators**](/docs/operators/) and [**Plots**](/docs/plots/) are the reference for building processing graphs.
- [**Python Library**](/docs/python/) is the reference for the `geoengine` Python package.
