This chapter describes the interfaces of the Geo Engine server.

- The [REST API](/docs/api/rest-api) is the interface for all clients: the web apps, the Python library and your own applications.
  It covers authentication, processing graphs, datasets, layers, permissions and more.
- The [OGC services](/docs/api/ogc) (WMS, WFS, WCS and OGC API Tiles) let standard GIS software like QGIS display and download results.

The [Python library](/docs/python/) wraps both, so data scientists rarely need to call them directly.
